## 这是什么

64 张切片卡 = 59 张看图诊断卡 + 5 张纯文字抽背卡。

每张卡：
- **问题区**只显示镜下图像（标题、病名、图注都已切掉）
- **答案区**显示**课件整页原图**——你看到的就是老师那页，外加逐字摘录的图注文字

## 怎么用

1. **随机抽 12 题**：打乱抽，自己先看图说诊断
2. 点「显示答案」核对，答案区能直接对照课件原页
3. 自评「记住了 / 没记住」，走完一轮可只练错题
4. 时间紧：点顶部 **★ 高频切片**（实验九总结过的 20 张）

## 已知边界（如实说明，请照这个用）

1. **自测图是裁出来的**：平台只给整页渲染图、文字烧在画面上（不像桌面 PPT 能隐藏文本框），所以我用「最大连通块 + 内向收缩」把镜下图像区切出来。裁切不完美的少数页，卡片上有标记。
2. **页内没印病名的页**：卡片标题写成「（该页未印病名）」。这类页我**没有**按页序推测填病名——那是推断，不是课件原文。
3. **患者面部照不放图**：实验五第 36 页原页含患者面部照，该卡改成纯文字抽背，不上患者照片。
4. **纯文字表格页**（实验六 24/33/40/47）做成文字抽背卡，内容逐字取表格原文。
5. **没做成卡的页**：整页无文字、只有切片编号（如 10-9、11-1）、纯大体照、正常组织学页——一律不做「看图说诊断」卡，避免让你对着没有答案的图猜。
6. **实验四到九的 38 个「切片任务点」是视频课**，不含图文；本次只用了 6 份课件（228 页）。视频里的老师讲解未转文字。
