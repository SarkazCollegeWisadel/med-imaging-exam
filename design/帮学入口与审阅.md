# 帮学入口与审阅

2026-11-25 · [帮学总入口](https://sarkazcollegewisadel.github.io/med-imaging-exam/learn/)

总入口按科目收录四个已发布的 GitHub Pages 学习站，现有 19 个网页入口，另附本地版 Study Desk 的搭建说明。课程内容和练习记录仍在各自工具里。原有阅片地址继续打开阅片工作台，同仓库的练习页也可以直接返回总入口。

后续补上了影像真题回练、环卫大纲自测、部分药物题课件依据和可导入的学习记录。下表保留首次审阅结果，进展及待补材料见 [跨设备学习记录](跨设备学习记录.md)。
