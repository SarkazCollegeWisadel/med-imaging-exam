# 帮学页面统一设计工作笔记

2026-11-24 · `med-imaging-exam`

## 设计决定

- 以已确认的阅片工作台为准。灰白桌面、灰梅色操作、石墨色文字。页名、章节和题干优先使用本机华文宋体，缺字或缺字体时由系统宋体接续。
- 折面放在页首与章节边界，答案展开沿上边缘起折。操作区保留玻璃材质，放在内容边界之外。放大、翻页和答题工具各占独立空间，医学影像与题干完整可见。
- 练习沿用各页的节奏。阅片保留图片尺度和图注，题库保留筛选、判分、错题与来源，指南保留目录、表格和章节跳转。正确、错误和提醒继续使用可区分的颜色。
- 页面使用相对链接，浏览器在同一标签页打开。子页可返回学习台或上一级科目，阅片工作台按标签页恢复片位和筛选。

## 后续维护

- 12 个子页的样式源在 [study-desk.css](study-desk.css)，阅片工作台沿用根页中已验收的交互与样式。共享样式负责视觉，各子页原有 HTML、题库和练习脚本负责内容与交互。
- 修改共享样式后，从仓库根目录运行 `python design/apply-study-desk.py`。脚本把样式内联到各子页，页面随仓库目录保存后，仍可断网跳转。只生成一页可加 `--page pharm/perio/index.html`。刷新整页题库时保留顶部导航，重新执行内联生成。
- 提交前运行 `python design/apply-study-desk.py --check` 和 `git diff --check`。新页先接上科目入口和「返回学习台」，再登记进生成器。
- 灯箱页码与放大浮条的位置以前遮住了片角。今后新增页码、评分或跳转控件，以内容流里的独立栏位为准。需要固定显示时，先核对最窄屏下控件与题干、原图、答案的边界。
- 补题页保留当前 197 题和来源校验，课程入口使用牙周与黏膜两个名称。原页曾把一个样式块写进另一个样式块，本次将两块分开。重生成时检查 CSS 边界和来源区域在系统深色设置下的对比度。
