# 跨设备学习记录

2026-11-25 · [帮学总入口](https://sarkazcollegewisadel.github.io/med-imaging-exam/learn/)

## 两个操作

1. **向 DSH 提问。** 在练习页点「学习记录 / 问 DSH」，检查学习位置，再点「复制给 DSH」，把题干或选中文字、位置及来源链接粘进你正在用的 DSH 会话。剪贴板受限时，页面会显示可长按复制的文本框。对其他站点，可回总入口选资料，再写具体章节或题号。
2. **向本机学习台存档。** 每完成一段学习，选择查阅、练习或复习，主动点「记下一条」。点「复制学习码」或「下载记录」，用自己的设备间传输方式带到电脑。双击本地「导入网页学习记录」并确认归档。账本保留原学习时间与来源，重复导入按 ID 去重，按新加坡日期更新已有摘要。

网页记录先留在浏览器。iPad、安卓、电脑分别生成的文件可依次导入同一个本机账本。学习码保存的是学习位置、动作、时间和出处，答题状态仍由原网页保存。问 DSH、打开网页和搜索都不会单独记成学习。

## 接入与维护

- [transfer.js](../learn/transfer.js) 和 [transfer.css](../learn/transfer.css) 提供页面操作。下载整站目录时保留 `learn/`，以便离线使用新增功能。
- [web_progress.py](web_progress.py) 放在本机 Study Desk 的 `kb/`，与 `study_memory/` 同级。使用带 Tk 的 Python 可打开粘贴窗口，也可命令行运行 `python web_progress.py --file 网页学习记录.txt`。导入使用同一个本机账本和日期摘要。
- 文本协议是 `STUDY-DESK/1` 首行与随后的一组 JSON 记录。导入校验 UUID、时间、动作及来源站点。任何模型回答、聊天转述、猜测掌握情况都不属于此事件。
- 如需以后从网页直达 DSH 并接收回执，需要先确认 DSH 可公开调用的分享入口；自动归档还需要明确的跨设备授权与传输方法。当前 clipboard / 文件方式使用浏览器原生能力，不依赖本机向手机开放端口。 [WebKit 剪贴板文档](https://webkit.org/blog/10855/async-clipboard-api/)

## 验收

- 用桌面 Chromium、安卓视口 Chromium 和 iPad 视口 WebKit 检查真题答错、筛选、重做、刷新保留、可手动复制文本与学习文件下载。
- 用临时账本导入浏览器生成的合成记录，检查同一份学习码重复导入只保留一个事件，并生成当天的 Markdown 与 JSON 摘要。
- 浏览器模拟覆盖了相应视口和引擎。实体设备及实际 DSH 会话由用户首次使用时验收。
