## 已知边界（如实说明）

1. **图上文字已去掉**：用 PowerPoint 逐页隐藏文本框后重导页图（`slides_clean/`），原件不动，「滤泡型」「丛状型」这类答案字不会露在图上。
2. **「图上带结构标注」3 页**：第 20 页「微小囊肿」、第 25 页「淀粉样物质/钙化」、第 45 页「影细胞/上皮基底层」的标注框是烧进图片里的，去不掉。会提示结构名但不给肿瘤名，已在卡片上逐张标出。
3. **4 页本身无图注**（第 11、14、17、40 页，页面只有「滤泡型」「11-1」等字样）：答案取相邻讲解页原文，卡片下方注明出处。
