## 怎么用

1. 先看图，自己说出诊断
2. 点「翻开答案」核对
3. 对不上或想知道为什么，点「📋 复制去问月下」，粘到 DSH 对话里问鉴别
4. 时间紧就先点顶部「只看真题考过的」——那是老师出题偏好的最硬证据（20 张）

## 标记说明

- ★ **真题考过**（20 张）：平台两套作业中出现的片子页
- **阅片陷阱**（8 张）：胸大肌、胸锁乳突肌、乳房似肺炎/似胸腔积液、乳头、肋软骨钙化、奇叶、颈肋——看着像病、本质是正常结构或变异
- ⚠️ **非典型影像片**：该页为示意图或照片，已在页面标注

## 已知边界（如实说明）

1. **`3.2 呼吸系统2.pptx` 无法打开**：平台把内嵌 OLE 对象剥离成 0 字节，PowerPoint 拒开。已试删零字节对象、删 rels 引用、删整个 graphicFrame、重新打包四种修法均失败。该课件 4 页已改用 `3.4 呼吸系统疾病` / `3.3 呼吸系统3` 的同款页替代，页面标「图取 XX（同款页）」，可自行核对。
2. **三张纯图页**（7.3 p101、7.4 p87、p81）图注在上一页，出处标为「第 X 页（讲解页）」。
3. **两处问法修正**：`6.1 p21` 图上实为卵圆形高密度影而非鹿角形；`3.1 p44` 是胸部 CT 轴位而非胸片。均已按实际图像改写问法。
4. 答案严格照抄课件图注，**不替代教材**；考试以老师课堂口径为准。

## 技术说明

- 单文件 HTML，图片 base64 内嵌，**断网可开**
- 各科帮学页面的设计规范、页面清单和样式更新方法见 [统一设计工作笔记](design/工作笔记.md)。
- 图片去字方法：PowerPoint COM 遍历 `Slide.Shapes`，对含文字的形状设 `Visible = 0` 后导出，**原件不修改**
- 判「真实影像片」用灰度层次判据（唯一灰度值 ≥90 且灰度熵 ≥4.2），避免把黑白线描示意图误判为片子
